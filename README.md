# موقع مِشكاة الرسمي

هذا الموقع **تعريفي/تسويقي فقط** لتطبيق مِشكاة، وليس موقعًا لعرض محتوى القرآن أو الكتب أو التفاسير.

## يحتوي على
- الصفحة الرئيسية وهوية التطبيق.
- صفحة جميع الميزات.
- دليل طريقة الاستخدام.
- صفحة تحميل APK.
- تصميم RTL عربي قريب من هوية التطبيق.
- صفحات مناسبة للفهرسة في محركات البحث.

## قبل النشر
1. عدّل `site-config.txt` وضع رابط الموقع الحقيقي في `SITE_URL`.
2. ضع رابط APK الحقيقي في `APK_URL`.
3. إذا كان APK مستضافًا داخل الموقع، ضع الملف في `downloads/mishkat.apk` واستخدم `APK_URL=downloads/mishkat.apk`.
4. استبدل `YOUR-DOMAIN.example` في `robots.txt` و`sitemap.xml` بالرابط الحقيقي.
5. ارفع الموقع على GitHub Pages.
6. أضف الموقع إلى Google Search Console وأرسل `sitemap.xml`.
